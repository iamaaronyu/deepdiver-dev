# 阶段 5：固定问题质量评测与成本控制

评测日期：2026-10-22。此阶段只在本机执行，不开放远程或公网访问。

## 固定评测与复现

`evals/research-v1.json` 固定 10 题，覆盖事实、比较、时效、来源冲突、信息不足五类。每题分别运行 standard（一轮）和 deep（两轮），每次尝试最多 $0.10，总声明上限 $2，并发为 2。每轮结果记录原问题、配置、源代码和题集指纹、原始材料、报告、逐题指标及价格快照。参考答案只用于复核，不注入研究过程。

```sh
.venv/bin/python -m deepdive.evaluation.runner --live --total-budget 2
.venv/bin/python -m scripts.report_evaluation data/evaluations/运行目录
```

真实调用必须显式使用 `--live`。评测库与用户任务库隔离。单题可以用 `--case sqlite-journals --profile deep --total-budget 0.1`，但小样本回归不能代替完整 20 次配对评测。

进程中断后，先确认原进程已停止，再运行：

```sh
.venv/bin/python -m scripts.resume_evaluation data/evaluations/运行目录 --confirmed-stopped
```

续跑保留已开始但未结束的尝试为中断失败，只提交从未开始的组合，不自动付费重试。运行期间代码指纹发生变化则拒绝提交后续任务。任何修改后的验证必须建立新运行目录，不能覆盖基线。

## 指标口径

- 完成率：流程 COMPLETED 数 / 所有已提交尝试；失败、中断不剔除。COMPLETED 可能只有部分证据报告，不代表答题合格，另列有分析报告数。
- 引用逐字有效率：可在本次抓取正文定位、来源已获取且任务关联合法的证据条数 / 证据条数。无证据时为 null，不是 100%。这不代表事实正确率，也不代表今天重新请求 URL 的成功率。
- 自动主张支持度：独立模型判定支持、词面关联、来源/版本/时效检查后的主张占比；重要主张另列。属于自动判断，不能独立证明准确率。
- 引用锚点有效率：分析引用落在合法且支持/部分支持主张上的数量 / 分析引用数。
- 关键词覆盖提示：只作为选词诊断，不能当作语义覆盖率。初版误把问题标题计入提示，基线原指标保留并在结果中说明；真正覆盖使用独立复核。
- 参考复核覆盖率：各题维度逐项评分（完整正确 1、部分回答 0.5、未回答或错误 0），逐题取平均，再按策略取所有尝试的平均。问题文本、来源列表、附录中的摘录不算作已回答。
- 参考复核事实错误率：抽查事实中错误项 /（正确项 + 错误项）。无法判定项不进入分母；全部无法判定为 null，不能把空报告当零错误。必须同时报告抽查事实数，不能泛化成整个产品准确率。
- 费用：保守峰时未缓存单价乘记录 token，加搜索和抓取请求；忽略优惠与减免。中断或用量缺失显示未知，仅列已知小计与预留上限，不当作实际账单。

复核保存于运行目录 `audits/`，绑定 task_id、每个维度评分、抽查事实与依据。此次为 Codex 基于外部官方资料的独立参考复核，不是人工认证，也不是待评报告的模型自评分。汇总命令每次生成新的 comparison JSON/Markdown/HTML 版本，不覆盖原始指标。

## 基线与限制

基线目录：`data/evaluations/20261022T022844Z-11a1ab`。两个已开始的任务因执行进程中断保留为失败，不能直接归因于模型策略。深度模式还出现结构化输出失败；真实结果必须保留，不能为达到 90% 完成率而排除。

已发现的质量问题包括：官方价格表已抓到，但选段遗漏价格行；泛化异步编程行为；分析审查过滤后只剩证据汇总；对缺少日期与实例信息的问题缺少可操作的条件方案。引用逐字有效并不能防止这些问题。

参考目录勘误：题集中的 Harbor metrics 路径 `administration/accessing-harbor-metrics/` 无效，应为 `https://goharbor.io/docs/2.14.0/administration/metrics/`；杭州文旅页面在参考检查时超时，不能声称该页面内容已验证。为保持基线指纹，原题集与运行快照不改写，后续题集版本再修订。其他会变的价格/版本参考也仅对本次检查日期有效。

阶段工程交付完成不等于质量门槛达成。未达到目标时保留失败、记录原因，修复后另建回归运行；少量回归成功仍不能宣称完整固定集已通过。

## 根据基线实施的修复

- 规划提示明确必需字段、长度和输出空间；校验失败记录安全字段路径，不保存原始输出或未知字段名。
- 第二轮计划结构异常时停止扩展，保留第一轮已核验材料继续成文，明确标为部分报告，不自动重试付费请求。
- 正文选段保留紧凑表格的表头、单位与数值，长段保留多个候选窗口，并覆盖不同问题维度，避免只选名称与介绍。
- 分析与独立审查可见完整表格摘录及来源 URL；强化版本、部署、日期与 CPU 并行条件检查，限制过长段落以减少截断。
- 新版覆盖提示排除题目和摘要，跨任务主张关联亦判为无效；旧运行的原始指标不回写。比较时以独立参考复核为准。

修复后离线测试：149 项通过。另以相同固定题集中的价格与 SQLite 两题执行独立 deep 回归，新增预算上限 $0.20，运行目录 `data/evaluations/20261022T113211Z-9e31bc`。小批次结果不能代替完整固定集重新评测。
